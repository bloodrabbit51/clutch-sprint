# Sprint Plan Guide

Follow these steps to build a complete sprint plan.

## 1. Create a Sprint
1. Click **Create New Sprint**.
2. Select a **Project**, **Start Date**, **End Date**, and **Fixed Days Holiday**.
3. Confirm the auto-generated **Sprint Name**.
4. Click **Create Sprint**.

## 2. Add People
1. Click **Add People**.
2. Enter the team member name and save.
3. Repeat for all team members.

## 3. Set Capacity
1. In the **People Management** table, enter **Leaves** and **Allocation %**.
2. **Available Days** and **Total Capacity** update automatically.

## 4. Add User Stories
1. Click **Add User Story**.
2. Choose **Backlog** to pull from Project Backlog, or **Other** to enter a custom story.
3. If **Backlog**, select a **Feature** and **User Story**.
4. If **Other**, enter **Name** and **Story Points**.
5. Click **Save**.

## 5. Assign and Confirm
1. Use **Assigned** to map stories to people.
2. Set **Status** to **Confirmed** to count toward utilization.
3. Review the utilization bars for capacity alignment.

## 6. Save the Sprint
1. Click **Save** once the plan is ready.
2. Saved plans appear in **Previous Sprints**.

Tips:
- **Confirmed** stories drive utilization. **Tentative** stories show as a ghost overlay.
- If you change dates or allocations, re-check utilization.
