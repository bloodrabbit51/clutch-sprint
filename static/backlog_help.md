# Project Backlog - How To Use

This page is where you build and maintain a project backlog. It is split into three parts: project selection, feature IDs, and user stories. Follow the steps below.

## Step 1 - Create or open a project backlog
1. Click "Create Project BackLog".
2. Pick a project in the dialog.
3. Click "Create".
4. The project backlog is now active and ready for editing.

You can also open an existing backlog from the list by clicking "Edit" next to a project.

## Step 2 - Add Feature IDs
1. Click "Create FeatureID".
2. Enter the feature or bug ID.
3. Enter a short description.
4. Click "Create".

### Importing features
1. Click "Import CSV" under Feature IDs.
2. Select a CSV with two columns: Feature ID, Description.
3. Errors (if any) appear below the tables.

## Step 3 - Add User Stories
1. Click "Create UserStory".
2. Select the Feature ID this story belongs to.
3. Enter the user story name.
4. Pick a tshirt size.
5. Click "Create".

### Importing user stories
1. Click "Import CSV" under User Stories.
2. Select a CSV with three columns: Feature ID, User Story, Tshirt Size (XS, S, M).
3. Errors (if any) appear below the tables.

## Table buttons - What each one does
### Feature IDs table
- Edit: Update the feature ID or description.
- Delete: Remove the feature and all its user stories.

### User Stories table
- Complete: Marks the story closed and moves it to the bottom of the list. Closed stories are hidden in the sprint plan picker.
- Open: Reopens a closed story so it can be used in future sprint plans.
- Delete: Removes the story from the backlog.

## Save / Delete backlog
- Save: Saves the backlog metadata so it shows in the saved list.
- Delete: Deletes the backlog for the current project, including features and stories.
